## 🔵 Giai đoạn 1 — System Analysis & Design (Tuần 1–2)

> **Tỷ trọng:** Backend 15% | Frontend 5%

---

### Tuần 1 — Chọn đề tài & Phân tích yêu cầu

#### Sinh viên cần làm
- Lập nhóm
- Chọn đề tài
- Phân tích:
  - Problem Statement
  - User Roles
  - Functional Requirements
  - Non-functional Requirements
- Thiết kế sơ bộ:
  - Use Case Diagram
  - ERD draft
  - Sitemap UI

#### 📦 Deliverables
- [ ] Proposal PDF
- [ ] Feature list
- [ ] Use Case Diagram
- [ ] ERD sơ bộ

#### 📝 Giảng viên đánh giá
- Phạm vi phù hợp
- Có business logic rõ ràng
- Có khả năng phân chia module

---

### Tuần 2 — Database Design & API Specification

#### Backend focus
- Thiết kế database
  - Quan hệ bảng

  - Seed data
- API Design:
  - Endpoint
  - Method
  - Request/Response
  - Status code

#### Frontend focus
- Wireframe giao diện
- Routing structure

#### 📦 Deliverables
- [ ] Database Diagram
- [ ] API Document
- [ ] UI Wireframe

#### 🔧 Công cụ gợi ý
- Swagger
- Postman
